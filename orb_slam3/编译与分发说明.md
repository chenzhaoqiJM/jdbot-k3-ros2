# ORB-SLAM3 RGB-D 编译与分发说明（ROS 2 Humble / RISC-V）

本文对应当前验证过的组合：ROS 2 Humble、OpenCV 4、Pangolin v0.9.4、
ORB-SLAM3 `4452a3c4ab75b1cde34e5505a36ec3f9edcdc4c4`。目标机器为
`riscv64`。`/opt/orbslam3` 是统一的运行与开发依赖前缀，不依赖某个用户的
home 目录。

## 1. 安装系统依赖

```bash
sudo apt update
sudo apt install -y git cmake ninja-build build-essential patchelf \
  libeigen3-dev libopencv-dev libboost-serialization-dev libssl-dev \
  libsuitesparse-dev libglew-dev libgl1-mesa-dev libepoxy-dev \
  libx11-dev libwayland-dev libjpeg-dev libpng-dev libtiff-dev
```

ROS 2 包还需要：

```bash
sudo apt install -y ros-humble-cv-bridge ros-humble-message-filters \
  ros-humble-tf2-ros
```

## /opt权限更改
sudo chgrp -R $(whoami) /opt
sudo chmod -R g+w /opt

## 2. 编译并安装 Pangolin

```bash
git clone --branch v0.9.4 --depth 1 \
  https://github.com/stevenlovegrove/Pangolin.git
cmake -S Pangolin -B Pangolin/build -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX=/opt/orbslam3 \
  -DBUILD_EXAMPLES=OFF -DBUILD_TOOLS=OFF -DBUILD_PANGOLIN_PYTHON=OFF
cmake --build Pangolin/build -j"$(nproc)"
cmake --install Pangolin/build
```

## 3. 编译 ORB-SLAM3

```bash
git clone https://github.com/UZ-SLAMLab/ORB_SLAM3.git
cd ORB_SLAM3
git checkout 4452a3c4ab75b1cde34e5505a36ec3f9edcdc4c4
git apply /path/to/orbslam3_ros2/patches/orbslam3-riscv64.patch
```

补丁完成四项兼容处理：在 RISC-V 上移除 `-march=native`；主工程改用
C++17；DBoW2/g2o 同样移除 `-march=native`；把 `mnFullBAIdx` 修正为其实际
使用所需的整数类型。

依次编译第三方库和主库：

```bash
cmake -S Thirdparty/DBoW2 -B Thirdparty/DBoW2/build \
  -DCMAKE_BUILD_TYPE=Release -DCMAKE_POLICY_VERSION_MINIMUM=3.5
cmake --build Thirdparty/DBoW2/build -j"$(nproc)"

cmake -S Thirdparty/g2o -B Thirdparty/g2o/build \
  -DCMAKE_BUILD_TYPE=Release -DCMAKE_POLICY_VERSION_MINIMUM=3.5 \
  -DG2O_EIGEN3_INCLUDE=/usr/include/eigen3
cmake --build Thirdparty/g2o/build -j"$(nproc)"

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_PREFIX_PATH=/opt/orbslam3 \
  -DCMAKE_POLICY_VERSION_MINIMUM=3.5
cmake --build build -j"$(nproc)"
```

若源码自带 `build.sh`，也可以使用它，但仍应保证上述补丁已应用，且
Pangolin 能从 `/opt/orbslam3` 被 CMake 找到。

## 4. 整理 `/opt/orbslam3` 分发目录

```bash
install -d /opt/orbslam3/{lib,include/orbslam3,share/orbslam3}
cp -a lib/libORB_SLAM3.so Thirdparty/DBoW2/lib/libDBoW2.so Thirdparty/g2o/lib/libg2o.so /opt/orbslam3/lib/
cp -a include/. /opt/orbslam3/include/orbslam3/

install -d /opt/orbslam3/include/orbslam3/Thirdparty/{Sophus,DBoW2,g2o}
cp -a Thirdparty/Sophus/sophus /opt/orbslam3/include/orbslam3/Thirdparty/Sophus/
cp -a Thirdparty/DBoW2/DBoW2 Thirdparty/DBoW2/DUtils /opt/orbslam3/include/orbslam3/Thirdparty/DBoW2/
sudo cp -a Thirdparty/g2o/g2o /opt/orbslam3/include/orbslam3/Thirdparty/g2o/

install -m 0644 Thirdparty/g2o/config.h /opt/orbslam3/include/orbslam3/Thirdparty/g2o/config.h

cp Vocabulary/ORBvoc.txt /opt/orbslam3/share/orbslam3/

patchelf --set-rpath '$ORIGIN' /opt/orbslam3/lib/libORB_SLAM3.so

echo /opt/orbslam3/lib | sudo tee /etc/ld.so.conf.d/orbslam3.conf
sudo ldconfig
```

上述命令只复制第三方头文件，不会带入 `build` 和 `lib` 子目录。当前机器
已经整理好了精简后的目录，并额外安装了
`lib/cmake/ORB_SLAM3/ORB_SLAM3Config.cmake`，下游可直接使用：

```cmake
find_package(Pangolin CONFIG REQUIRED)
find_package(ORB_SLAM3 CONFIG REQUIRED)
target_link_libraries(your_target PRIVATE ORB_SLAM3::ORB_SLAM3)
```

## 5. 编译 ROS 2 包

```bash
source /opt/ros/humble/setup.bash
cd ~/orbslam3_ws
export CMAKE_PREFIX_PATH=/opt/orbslam3:${CMAKE_PREFIX_PATH}
colcon build --symlink-install --cmake-clean-cache \
  --cmake-args -DCMAKE_BUILD_TYPE=Release
source install/setup.bash
```

运行时无需设置指向 home 目录的 `LD_LIBRARY_PATH`：

```bash
ros2 launch orbslam3_ros2 rgbd.launch.py
```

默认词典来自 `${ORB_SLAM3_PREFIX:-/opt/orbslam3}/share/orbslam3/ORBvoc.txt`，
相机参数通过 ROS 2 package share 动态定位。也可在命令行覆盖：

```bash
ros2 launch orbslam3_ros2 rgbd.launch.py \
  vocabulary:=/another/location/ORBvoc.txt \
  settings:=/another/location/camera.yaml
```

## 6. 打包和部署

打包

```bash
tar czf orbslam3.tar.gz orbslam3
```

部署

```bash
sudo tar xzf orbslam3.tar.gz
```

目标机解压到 `/opt`，安装上述系统动态库和 ROS 2 依赖，再

```bash
echo /opt/orbslam3/lib | sudo tee /etc/ld.so.conf.d/orbslam3.conf
sudo ldconfig
```

该包是 RISC-V 二进制包，不能直接用于 x86_64/ARM；目标机的 glibc、OpenCV、Boost、OpenSSL ABI 也应与构建机
兼容。跨发行版分发时，建议在目标系统上按本文重新编译。
